AudioVault

A private, high-performance desktop media manager and Google Drive streaming engine.

About the Application

AudioVault is a personal Linux desktop application built to index, organize, and stream personal audio and video libraries stored securely in user-owned Google Drive storage. It provides native desktop integration, local caching, and custom audio processing.

Privacy Policy

Effective Date: October 2026

AudioVault complies with the Google API Services User Data Policy, including the Limited Use requirements:

  • Local-Only Operation: AudioVault connects to Google Drive APIs exclusively using the user personal OAuth credentials to fetch media file metadata and stream media streams directly to the local player.
  • No Remote Data Collection: AudioVault does not host any remote backend servers. No user files, tokens, personal identifiers, or media data are collected, tracked, or sent to any third-party servers.
  • Credential Storage: OAuth tokens and refresh tokens are stored exclusively on the user local filesystem and are never shared.
  • No Advertising or Profiling: User data is never sold, leased, or utilized for advertising, marketing, or behavioral profiling.

Terms of Service

AudioVault is provided for personal, private utility use. Users are responsible for maintaining the confidentiality of their own Google Cloud OAuth credentials.
